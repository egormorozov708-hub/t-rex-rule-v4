# t-rex-rule-v4

Детерминированное правило `rule_v4` для Chrome Dino: 1,31 млрд кадров без смертей в быстром режиме, JS-эталон и проверенное Python-зеркало.

## Результаты 📊

| Режим | Seeds | Игр × кадров | Смертей | Кадров сыграно |
| --- | --- | --- | --- | --- |
| `rule_v3`, fast | 786000–786029 | 30 × 200 000 | 1 (seed 786003, кадр 155 709) | 5 955 709 |
| A/B v3 → v4, 1M | 790000–790029 | 30 × 1 000 000 | v3: 1 (seed 790015, кадр 602 061) · **v4: 0** | v3 29 602 061 · v4 30 000 000 |
| `rule_v4`, fast 1M | 791000–791029 | 30 × 1 000 000 | 0 | 30 000 000 |
| `rule_v4`, ночь | 800000–800130 | **131 × 10 000 000** | **0** | **1 310 000 000** |
| `rule_v4`, реальный режим | 792000–792002 | 3 × 50 000 | 0 | 150 000 |

Реальный режим: seed 792001 сначала дал `TIMEOUT` от сторожа на 36 805 кадрах и прошёл после перезапуска; в таблице учтён успешный rerun (50 000 кадров).

Верхняя 95%-граница частоты смерти по правилу трёх: **≈2,2·10⁻⁹ на кадр** (≈1 смерть на 457 млн кадров) по всем бессмертным играм; по одной ночи ≈2,3·10⁻⁹. Подробности — [`results/FINAL_RESULTS.md`](results/FINAL_RESULTS.md).

## Как это работает ⚙️

- Прыжок, когда `dist ≤ max(25, 17 · speed)`; пока динозавр в прыжке, новый прыжок не инициируется.
- Птеродактиль: `oy 60–90` → присед, `oy ≥ 95` → прыжок при `dist ≤ порог + 25`, иначе бежать. `DROP` (ускоренное приземление) — если прыжок уже начат, препятствие, через которое он начался, пройдено, а впереди большой кактус или низкий птеродактиль (oy ≥ 95).
- Быстрый режим: `requestAnimationFrame` выключен, время подменено виртуальными часами `dt = 1000/60`, вся игра считается внутри страницы одним `page.evaluate`. Это даёт воспроизводимость по seed и ≈61 000 кадр/с.
- Канонична JS-логика (`RULE_V4_JS` в `rule_v4.py`); Python-зеркало служит только для parity: **7 seed × 200 000 кадров, MATCH 7/7** по действиям, кадрам и `distanceRan`.

## Быстрый старт 🚀

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
```

```bash
python parity_v4.py --js-only --cap 3000 --seeds 792000   # проверка: 22 495.5
python watch.py --agent rule_v4 --cap 50000 --games 3 --seed0 792000
python parity_v4.py --cap 200000                           # parity Python/JS
python night_run.py --deadline 06:00                       # ночной sequential-прогон
```

Игры идут только последовательно. См. [`INSTALL.md`](INSTALL.md).

## Ограничения ⚠️

- «Бесконечно» не доказано — измерен только верхний предел частоты смерти. Оценка по правилу трёх предполагает независимые кадры, а правило v4 подбиралось по смертям seed 786003 и 790015, поэтому цифра ориентировочная.
- RL-подходы (табличные v3–v6, DQN) не воспроизвели это правило.
- Реальный режим проверен малой выборкой; один запуск потребовал перезапуска после таймаута.
- Python-зеркало проверено на 7 seed; при расхождении правят JS-эталон.
- Игра загружается с `https://wayou.github.io/t-rex-runner/`; исходники игры в репозиторий не входят.
